# 更新记录

[返回首页](../README.md) · [使用指南](usage.md) · [开发与构建](development.md)

根据已有项目记录整理，具体问题分析见[已知问题](known-issues.md)。

## 0.3.5

- 登录自启支持关闭、普通权限和管理员权限三种模式，选择后点击“应用设置”。管理员模式使用当前账户的最高权限登录任务，解决手动提权后重启仍恢复普通权限的问题。
- 普通入口与管理员任务相互迁移，取消 UAC 保留原配置，失败尝试回滚；更换发布目录后可重新应用设置更新路径。
- 托盘唤出面板时交接前台激活权限，支持被遮挡窗口激活、最小化恢复和最大化状态保留；用户切到其他窗口后取消延后激活。
- 托盘“登录自启设置…”直达设置页；登录时托盘尚未就绪会重试注册图标。

## 0.3.4

- 使用沉浸式标题栏，统一“统计概览 / 应用统计 / 设置”导航，移除重复标题与应用数量卡片。
- 概览按实时活动、日期统计、累计用量分组；日期筛选与每日统计放在一起，日均和峰值归入趋势图。
- 增加全历史累计与五键累计用量，不随所选日期或趋势区间变化。
- 新增左键 / 右键、1 秒 / 3 秒手速测试，显示点击次数、CPS 和折算 APM。

## 0.3.3

- 按键优先按点击命中的窗口归属，并处理鼠标捕获，减少普通窗口切换时的未知应用记录；不改写历史未知记录。
- 托盘退出在保存完成后通知面板关闭；采集器持续离线 8 秒时兜底关闭，最小化时同样有效，提权接棒保留面板。
- 新增近 30 分钟、近 1 小时点击数、鼠标 APM、活动点评和强度徽标。短时汇总只保留在内存中，重启采集器后重新热身。

## 0.3.2

- 在全部页面顶部显示普通权限提醒，检测到更高权限应用时强调漏记风险，可直接提升采集权限。
- 按输入位置识别主屏、副屏任务栏操作，兼容副屏负坐标，避免依赖窗口切换瞬间的前台句柄。

## 0.3.1

- 发布根目录保留单个 EXE 入口，将界面、运行库与语言资源统一放入 `runtime`。
- 修复 small 与 portable 多目录共存时的启动路由，启动入口打开自身目录对应的界面。
- 同级存在同版本完整便携目录时，共享运行时入口优先转到便携界面。

## 0.3.0

- 撤回额外的 Win32 窗口承载与逐帧渲染回调，恢复标准 WinUI 3 Window。
- 固定应用自带的 Windows App SDK 2.5.1，处理本机 Windows 10 上的窗口拖动滞后问题。
