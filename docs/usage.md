# 使用指南

[返回首页](../README.md) · [开发与构建](development.md) · [更新记录](changelog.md)

## 启动与退出

- 完整解压便携包，双击根目录的 `MouseClickStats.exe`，同时启动后台采集器和统计面板。
- `runtime` 包含界面与运行库，必须和主程序一起保留，不能只复制根目录的 EXE。
- 关闭面板后，后台仍在托盘中运行；从托盘重新打开面板，或选择“退出”保存统计并结束程序。
- 只想启动后台时，使用 `MouseClickStats.exe --background`。
- 升级前先从托盘退出旧后台，并关闭旧面板，再运行新目录中的程序。

## 权限与登录自启

程序默认使用普通权限。若游戏或其他应用以管理员权限运行，普通权限采集器可能漏记输入。在设置中选择“以管理员权限重启采集器”，通过 Windows UAC 确认后生效；取消时原后台继续运行。界面保持普通权限。

手动提权只影响本次运行。要在下次登录时继续使用管理员权限，请在“设置 → 登录自启权限”选择模式，并点击“应用设置”。

| 模式 | 登录后的行为 |
| --- | --- |
| 关闭 | 不自动启动 |
| 普通权限登录自启 | 以当前用户普通权限启动 |
| 管理员权限登录自启 | 通过当前用户的计划任务，以最高权限启动 |

管理员自启的配置、切换或关闭可能需要 UAC 确认；取消时保留原配置。任务仅在当前账户已登录的交互会话中运行，不保存密码，不使用 SYSTEM 账户。UAC 确认时应使用同一 Windows 账户，避免切换账户后使用不同数据目录。更换程序目录后，重新应用设置以更新启动路径。

## 统计规则

| 项目 | 口径 |
| --- | --- |
| 点击 | 左键、右键、中键、两个侧键分别累计；按下记一次，双击记两次，长按不重复计数 |
| 滚轮 | 上下、横向滚轮单独统计；120 原始增量折算一格，保留不足一格的精度，不计入点击总数 |
| 应用归属 | 按键优先按点击位置的窗口归属，存在鼠标捕获时跟随捕获窗口；滚轮优先按前台应用归属 |
| 任务栏 | 主屏、副屏的标准 Windows 任务栏交互单独统计，不猜测归给被切换的应用 |
| 日期与累计 | 按本地日期分组；累计用量读取全部历史，不受所选日期或趋势区间影响 |
| 多个鼠标 | 所有鼠标合并统计，不区分设备，也不估算硬件剩余寿命 |

应用优先按完整路径识别；路径不可读时尝试可执行文件名，同名兜底记录会合并，并以 `process-name:` 标记。仍无法识别的输入归入“未知应用”，历史未知记录不会重新猜测归属。

五键按设备标准标志统计，不随 Windows 的交换主次按钮设置改名。厂商 DPI、宏键需要映射为标准鼠标键才会计入；驱动和宏事件不能可靠还原为机械开关的实际按压数。

统计反映程序收到的输入，不代表目标应用实际接受了输入。窗口切换、透明覆盖层、队列延迟、进程查询失败和第三方任务栏可能造成误差。不统计安全桌面、登录界面或其他用户会话。

## 实时活动与手速测试

实时活动卡片显示近 30 分钟、近 1 小时的点击数，以及鼠标 APM 和活动点评。前 5 分钟为热身，满 30 分钟后显示 APM，计算方式为近 30 分钟的五键点击数 ÷ 30；不包含滚轮与键盘。

- 近半小时达到 1800 / 3600 / 6000 次时，分别进入忙碌、超频和“星际争霸职业选手！”档位；一小时达到 10000 次时显示破万点评。
- 不足完整窗口时标出已观察时长；暂停时停止采集，时间窗口继续滚动。查看历史日期时不混入实时活动。
- 短时汇总只保留最近 60 分钟，存放在采集器内存中。关闭再打开面板可以继续查看；重启采集器后重新热身，不会新增逐次事件记录。

概览中的“手速测试”支持左键 / 右键、1 秒 / 3 秒。首次有效鼠标按下开始计时，截止时刻起不再计数；双击记两次，长按不重复，不接受键盘、触摸或其他鼠标键。

结果显示点击次数、CPS（次数 ÷ 秒数）和折算 APM（CPS × 60）。点击“重新测试”可开始下一轮；关闭弹窗会取消本轮结果，成绩不持久化。后台未暂停时，真实测试点击仍计入日常统计。

## 数据保存、备份与清空

数据保存在 `%LOCALAPPDATA%\MouseClickStats\stats.db`，使用 Windows 自带的 SQLite 和 WAL 模式。程序不联网、不上传统计，不保存逐次事件、鼠标轨迹、窗口标题或键盘内容。

- 后台通常每 30 秒保存一次；面板可见时约每秒请求保存并异步读取，因此显示可能落后一个刷新周期。
- 写入失败会回滚、保留内存增量并重试。强制结束、断电或退出时仍无法保存，可能丢失尚未保存的部分；未收到的历史输入无法补记。
- 备份前请正常退出后台，再复制数据库。运行中不能忽略 `-wal` 文件而只复制主文件。
- “设置 → 清空统计数据”在确认后删除全部日期、全部应用的记录，不可撤销；保留自启和暂停选择，累计用量重新计算。
- 清空成功后同时清除短时旧计数，清空期间的新点击继续保留；失败时回滚。暂停状态只保留到本次后台退出。

## 兼容性与诊断

默认使用 Raw Input。全屏游戏、特定反作弊、睡眠与设备恢复，以及不同鼠标回报率下的表现，需要在相应环境实测，不承诺所有游戏兼容。跨权限漏记应优先检查采集权限。

需要排查时，在发布目录中运行以下命令：

```powershell
# 请求后台与界面分别生成诊断汇总。
.\MouseClickStats.exe --diagnose
.\runtime\MouseClickStats.UI.exe --diagnose

# 正常保存并退出后台；单独关闭面板。
.\MouseClickStats.exe --stop
.\runtime\MouseClickStats.UI.exe --close
```

报告保存在数据目录的 `diagnostics.json` 和 `ui-diagnostics.json`，仅在请求时写入，不是逐次事件日志。后台报告包含权限级别、Raw Input 包数、错误数和按应用的五键汇总；界面报告包含定时刷新、查询、数据更新、移动状态及消息耗时。

如需诊断其他输入兼容问题，先正常退出后台，再用 `MouseClickStats.exe --compatibility` 启动。兼容通道补充按键事件，不补充高精度滚轮，也不能解决跨权限漏记；极端调度延迟和多设备同键等情况仍需核对。运行库与界面问题见[已知问题记录](known-issues.md)。
